# Quakler 🦆

Quakler is a proprietary macOS application built for newsrooms to process, trim, format, and transcribe video efficiently locally without cloud dependencies.

## Features
- Convert video to H.264 or H.265 (HEVC).
- Center crop 16:9 to 9:16 for social media.
- Hard-burn subtitles automatically generated by OpenAI Whisper.
- Normalize broadcast audio levels.
- Add corner watermarks.
